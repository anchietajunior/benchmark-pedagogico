# Repository instructions

## Git workflow

Work directly and exclusively on `main` in this repository.
Keep all new changes and commits on `main`; do not create feature branches or branch-based worktrees.
When asked to publish, push `main` to `origin/main` without rewriting shared history or force-pushing.
This repository-specific user preference overrides default workflow suggestions to create a branch before editing or committing.
Apply this rule only to this repository, unless the user explicitly changes it.
